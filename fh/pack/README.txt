FNH v@VERSION@
==============

Fabric n Horizon — your Fabric, Minecraft: Java Edition and Horizon instances in a native
Windows 11 launcher.

Unzip this folder anywhere you can write to and double-click FH.exe. No installer, no Java setup
up front, and no background service are required.

Quick guide:

  - Click "Add Instance..." (or press Ctrl+N) to create a Fabric, Vanilla or Horizon instance.
  - Select an instance and click "Launch" (or double-click it) to play, and "Kill" (Ctrl+K) to
    stop a running game.
  - Click "Edit..." (Ctrl+I) to view Minecraft Log, manage Fabric Loader in Version, toggle mods
    in Mods, browse Worlds, or adjust memory, JVM flags and window size in Settings.
  - Click "Accounts" in the top-right toolbar to add or switch Microsoft accounts.
  - Click "Settings..." to switch between Windows 11 (System), Windows 11 Light and Windows 11
    Dark, pick an accent colour, or change instance sorting.
  - Hold Ctrl + Shift + Alt while clicking "Add Instance..." to wipe all FNH data (instances,
    accounts, saves, mods, caches, settings and logs) and relaunch FNH as a brand-new install.

Where files live on Windows:

  %APPDATA%\horizon-launcher\fh\ui.cfg        window theme and layout preferences
  %APPDATA%\horizon-launcher\fh\fh.log        launcher log
  %APPDATA%\horizon-launcher\instances.json   instance metadata
  %APPDATA%\horizon\instances\                per-instance game folders, mods and saves
