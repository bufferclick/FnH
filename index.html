What it is

FNH is a single native desktop program by Buffer, not an installer and not a web page. Unzip it, double-click FH.exe, and manage isolated Fabric, Minecraft: Java Edition, and Horizon instances from a multi-window Windows 11 shell modelled on JLac.

Every instance lives under its own isolated folder inside %APPDATA%\FnH with dedicated mods, resource packs, shader packs, worlds, servers, screenshots, options.txt settings, and live game console window.

Features

Multi-window Windows 11 UI
Modelled on Buffer's JLac (WinUI 3): grouped instance grid & list views, 9-page global Settings window, 11-page per-instance editor window, 61 built-in icons + custom icon picker, and Dark, OLED Dark, Light & System themes.
Modrinth, Horizon Registry & Auto-Port
Browse and install mods, resource packs, and shaders directly inside FNH, or drag-and-drop .jar, .hmod, .hnmod, and mod folders (Fabric jars dropped on Horizon auto-port via horizon-port-pack).
Fabric & Horizon instances
Create Minecraft: Java Edition instances with Fabric (or vanilla) from Mojang's version list, or spin up isolated Horizon instances with channel/build pinning and wgpu tuning.
Microsoft sign-in & offline play
One-click Microsoft device-code flow copies the code to your clipboard and opens the sign-in page automatically, alongside instant offline launch support.
Worlds, Servers & options.txt
Join worlds or servers in one click, install datapacks, export world .zip backups, edit servers.dat, and tune options.txt before launching.
Live console & launcher log
Real-time game stdout/stderr viewer with search and level filters, plus full launch diagnostics in %APPDATA%\FnH\logs\fh.log.

Install

  1. Download FnHLauncher.zip from Releases.
  2. Unzip it anywhere you can write to — %LOCALAPPDATA%\FNH, your desktop, a USB stick.
  3. Double-click FH.exe (future updates install automatically right inside FnH).

Nothing else is needed: no .NET, no Visual C++ redistributable, no Java until a Minecraft: Java Edition instance needs it, and FNH offers to fetch one then.
