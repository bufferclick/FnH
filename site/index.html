FNH

Fabric n Horizon. A native Windows 11 launcher for your Fabric, Minecraft: Java Edition and Horizon instances — clean WinUI 3 layout, per-instance mods, worlds, logs and loader control.

Download for Windows View on GitHub

Windows 10 or 11 · x64 · MIT licence

What it is

FNH is a single program, not an installer and not a web page. Unzip it, double-click it, and a window opens on the instances the Horizon launcher already has.

It shares the launcher's data folder and the launcher's own code, so builds, worlds, options and the Microsoft sign-in are the ones you already have. The two can be installed side by side, and FNH writes nothing to an instance the launcher would not write itself.

Features

Windows 11 UI
Modeled directly on JLac's Windows 11 (WinUI 3) layout and palette — grouped instance grid, top toolbar, right action bar, status bar with playtime, and automatic Light and Dark modes.
Version, Mods, Worlds, Logs
Pin or update Fabric Loader, enable or disable mods/*.jar files, inspect saved worlds, read latest.log, and tune memory and JVM flags per instance.
Fabric & Horizon instances
Create Minecraft: Java Edition instances with Fabric (or vanilla) from Mojang's version list, or spin up isolated Horizon instances in one click.
Microsoft sign-in
The device-code flow in the window: the code goes on your clipboard and Microsoft's page opens with it filled in. No app registration, nothing to configure.
Signed in when you join a server
The game is started with a read-once session file, the same hand-off the launcher's Play makes, so servers do not ask you to sign in again.
A log of every step
Each launch writes what it did — including the game's command line — to %APPDATA%\horizon-launcher\fh\fh.log.

Install

  1. Download the zip from Releases.
  2. Unzip it anywhere you can write to — %LOCALAPPDATA%\FNH, your desktop, a USB stick.
  3. Double-click FH.exe.

Nothing else is needed: no .NET, no Visual C++ redistributable, no Java until a Minecraft: Java Edition instance needs it, and FNH offers to fetch one then.
